# OnlineTrimmer 🎬 🎵 📄

> Free, browser-native media utility platform. Trim videos, cut audio, split PDFs, and sign documents 100% client-side with complete privacy and zero server uploads.

[![Build & Validate](https://github.com/USERNAME/onlinetrimmer/actions/workflows/ci.yml/badge.svg)](https://github.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## ✨ Features

- **Video Trimmer**: Lossless frame-accurate trimming for MP4, MOV, WebM, AVI, and MKV files.
- **Audio Cutter**: Interactive audio waveform editing with fade-in/fade-out and microsecond markers for MP3, WAV, and M4A.
- **Split PDF**: Instant extraction of selected pages or custom ranges with vector accuracy.
- **Sign PDF**: Electronic signature pad with smooth vector drawing and canvas export.
- **100% Client-Side Privacy**: Files never leave the browser. Zero server uploads.
- **SEO & GEO Ready**: Structured JSON-LD schemas (HowTo, FAQPage, SoftwareApplication, TechArticle), `llms.txt`, and `robots.txt`.
- **Google AdSense Compliant**: Privacy Policy, Terms of Service, Cookie Policy, About Us, Contact Us, and `ads.txt`.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Media Engines**: HTML5 Canvas, Web Audio API, WebAssembly
- **PDF Manipulation**: `pdf-lib` + `pdfjs-dist`
- **Icons & Motion**: `lucide-react` + `motion`

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/onlinetrimmer.git
cd onlinetrimmer

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
